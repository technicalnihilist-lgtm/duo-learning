Four sections, one loop

Learn, translate, practise, and watch the streak build.

Learn

A path, not a playlist

Units, lessons and checkpoints with real vocabulary and correct translations. Answers accept valid alternatives — accents still count.

  • Multiple choice
  • Typed translation
  • Word matching
  • Scrambled sentences
  • Fill the blank
  • Listening
  • Correction
Translate

Real translation, on device

A genuine ML Kit engine — not canned strings. Direct translation between any two supported languages, with detection, history and saved pairs.

  • Auto-detect
  • Swap
  • Copy · share
  • Pronunciation
  • Offline models
Practice

Spaced repetition

Flashcards scheduled with SM-2, a difficult-words drill, and revision built from the translations you chose to keep.

  • SM-2 scheduling
  • Due today
  • Tricky words
  • Saved phrases
Progress

Streaks that tell the truth

Streak maths runs on your local calendar day, so it never double-counts at midnight or resets when you cross a time zone.

  • Daily goal
  • XP
  • Achievements
  • Learning calendar

03

How it is built

No backend. No key in the APK. Everything that matters runs on the phone.

Language
Kotlin with Jetpack Compose and Material 3
Storage
Room (SQLite) for progress and vocabulary, DataStore for settings
Translation
Google ML Kit on-device models — free, no API key, works offline
Speech
Android TextToSpeech, with a clear message when a voice is missing
Build
GitHub Actions compiles the APK and attaches it to every tagged release
Privacy
No account, no analytics, no ad SDK — your text never leaves the device
